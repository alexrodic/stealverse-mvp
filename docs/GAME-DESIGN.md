# Game design reference

## Core loop

1. **See it** on the object radar.
2. **Steal it** into a carry slot and gain Heat.
3. **Escape** via a safe return or risky public extraction.
4. **Collect** base income and display discoveries.
5. **Upgrade** the base, find bigger worlds, and repeat.

Heat is global, bounded 0–100, and deliberately readable: 40 activates guards, 65 draws bounty hunters, and 85 locks drones onto exits. A public extraction pays 2× but can lose the object when Heat is elevated; a safe return pays 1× and lowers Heat.

The content model supports ordinary things becoming absurd targets: chairs, cars, cities, moons, planets, and eventually the universe. Rarity is a content signal; mutation is a visual/live-event modifier plan.
