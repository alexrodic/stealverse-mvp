# LiveOps systems

`src/data/events.ts` holds the current event rotation: 100x Luck, Zero Gravity, Meteor Shower, Alien Invasion, Secret Spawn, Gold Rush, Moon Crash, and Everything Is Giant. The hub lets a demonstrator switch the highlighted event locally; a real release should switch only from a server-owned schedule.

Announcements are local activity records. Demo analytics are illustrative UI metrics and must not be represented as production DAU, player telemetry, or server analytics.

Seasonal worlds are content containers: Haunted Suburb, Neon Mega City, Dino Island, and Moonfall. Entitlements are deliberately limited to cosmetics, display slots, visual trails, emotes, and nameplates. Luck trails and event passes are presentation concepts only and must not confer gameplay advantage.
