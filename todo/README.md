# To-do List App

Simple, dependency-free to-do list application that stores tasks in the browser's localStorage.

How to use
1. Open todo/index.html in your browser (or serve the repo root). 
2. Add tasks, mark them complete, edit, delete, filter, and clear completed tasks.

Notes
- Data persists per browser using localStorage under the key `stealverse_todos_v1`.
- This is intentionally small and framework-free so it can be integrated into the existing project easily.
